# 分子生物学实验 PCR-电泳异常智能复盘助手 · 精修版设计规范

## 1. 页面定位

这是一个项目展示型首页，而不是后台管理首页。页面用于竞赛展示、项目说明和角色入口引导，视觉上保持 IBM Carbon inspired 的专业、克制和结构化，同时加入蓝绿色实验室识别。

## 2. 颜色规范

核心颜色控制在五类，避免杂色。

| 用途 | 色值 | 使用方式 |
| --- | --- | --- |
| 深实验蓝 | `#0B1F3A` | Hero 背景、深色问题区、底部状态区 |
| 诊断蓝 | `#2563EB` | 主按钮、流程关键节点、能力强调线 |
| 凝胶青 | `#0EA5B7` | 电泳条带、证据高亮、科技感辅助色 |
| 浅背景 | `#F6FAFC` | 页面主体背景 |
| 卡片白 | `#FFFFFF` | 能力卡片、流程卡片 |
| 边框浅蓝灰 | `#D8E3EA` | 卡片边框、分割线、轻量结构线 |
| 正文黑 | `#161616` | 正文与标题 |
| 次级文字 | `#525252` | 说明文字 |

状态色仅用于底部摘要和提示：

- 开放 / 成功：`#24A148`
- 待验证 / 警示：`#F1C21B`
- 错误：`#DA1E28`

## 3. 字体层级

字体建议：

```css
font-family: "IBM Plex Sans", "Microsoft YaHei", "PingFang SC", "Helvetica Neue", Arial, sans-serif;
font-family-mono: "IBM Plex Mono", "SFMono-Regular", Consolas, monospace;
```

层级建议：

| 层级 | 大小 | 字重 | 行高 | 用途 |
| --- | --- | --- | --- | --- |
| Hero 标题 | 44-72px | 300 | 1.08 | 项目名称 |
| 区块标题 | 30-44px | 300 | 1.18 | 五个首页区块标题 |
| 卡片标题 | 18-21px | 600 | 1.34 | 问题、流程、能力卡片 |
| 正文说明 | 15-18px | 400 | 1.56-1.62 | 副标题与卡片说明 |
| 标签 / 序号 | 12px | 400 | 1.33 | Kicker、序号、状态标签 |

## 4. 卡片规范

问题卡片：

- 深色半透明背景，置于深实验蓝区块中。
- 使用 `1px` 浅蓝灰透明边框。
- 第一张卡片可使用凝胶青轻微高亮，形成视觉重点。
- 顶部保留序号和线性图标，正文底部对齐。
- 三张卡片高度一致，桌面端三列排列。

流程卡片：

- 白色或近白色背景。
- `1px #D8E3EA` 边框。
- 轻微阴影：`0 16px 40px rgba(11, 31, 58, 0.08)`。
- 每步使用 44px 方形编号节点。
- 桌面端六列横向蛇形排布，偶数卡片下移 42px。

能力卡片：

- 白色卡片，顶部 3px 蓝绿强调线。
- 线性科技图标统一放在 48px 图标盒中。
- 高亮卡片使用浅青色渐变背景，不只依赖边框。
- 桌面端四列，平板端两列，移动端单列。

底部状态卡片：

- 深蓝半透明面板。
- 使用小圆点表示状态。
- 入口信息轻量展示，不做后台表格。

## 5. 按钮规范

主按钮：

- 背景：`#2563EB`
- Hover：`#1D4ED8`
- 文字：白色
- 高度：48px
- 圆角：0px
- 阴影：仅主按钮使用轻微蓝色阴影

次级按钮：

- 背景：透明或深色半透明
- 边框：浅蓝灰透明描边
- 文字：白色
- 用于“教师复核入口”

弱化按钮：

- 背景：透明
- 边框：灰色透明描边
- 文字：浅灰
- 用于“开发调试入口”

## 6. 间距规范

- 最大内容宽度：`1240px`
- 页面左右安全边距：桌面 32px，移动 16px
- 首页区块上下间距：88px
- 移动端区块上下间距：64px
- Hero 内左右列间距：48px
- 卡片间距：16px
- 卡片内边距：24px
- 流程卡片内边距：18-20px
- 顶部导航高度：56px
- 按钮高度：48px

## 7. Streamlit 落地说明

1. Hero 区可用 `st.container()` 加自定义 HTML/CSS 实现，右侧抽象凝胶符号建议保留为 SVG / HTML + CSS，不依赖复杂动画。
2. 顶部导航可以用 Streamlit 的普通链接或 `st.page_link` 替代，首页仍保持展示型布局。
3. 三个入口按钮分别映射到学生诊断页、教师复核页、开发调试页。
4. 问题区、流程区、能力区都适合封装为可复用组件函数，便于后续维护。
5. 流程区桌面优先展示六步横向蛇形；Streamlit 中可用 `st.columns(6)` 实现，窄屏时改为两列或单列。
6. 电泳视觉不应使用真实泳道文字标注，保持品牌符号感。
7. 底部状态区只展示轻量状态摘要，不放筛选器、表格或后台控件。
