# Windows 安装与启动说明

更新：2026-10-08。适用于 Windows 10/11 的 64 位电脑。

## 当前项目电脑

双击项目根目录“启动生物实验智析助手.bat”。启动窗口出现后会自动打开浏览器，不需要输入命令。也可以双击“创建桌面快捷方式.bat”，以后直接双击桌面图标。

项目文件夹必须保留，快捷方式指向其中的运行环境。移动整个文件夹后重新创建快捷方式。当前项目继续使用原有配置、data/app.db 与 uploads，不自动迁移或复制个人数据。

启动窗口显示服务状态；关掉浏览器不代表关闭服务。结束时先保存页面内容，再在启动窗口点击“退出系统”。重复双击会打开已有服务页面，不另起同一份服务。端口被占用时自动选择另一个本机端口。

## 发给另一位教师

把 dist/BioLabReview-Setup-2026.10.08.exe 发给对方。安装包已包含 Python 与应用依赖；对方无需自行安装 Python 或执行命令。安装不需要下载依赖，AI 在线功能仍需要网络和自己的 DeepSeek Key。

对方双击安装包，安装完成后双击桌面“生物实验智析助手”。首次在启动窗口点击“首次使用配置”，设置教师访问码，可选填 DeepSeek API Key 和调试访问码。保存后退出并重新启动即可生效；没有 Key 时仍可使用人工及本地规则流程。

安装版程序放在 `%LOCALAPPDATA%\Programs\BioLabReview`；课堂数据库、图片和配置单独保存在 `%LOCALAPPDATA%\BioLabReview`。每台电脑是独立数据，不自动与另一台电脑或学生手机同步。安装包不包含作者的 Key、入口码、真实数据库或照片。

更新前先退出系统，再运行新版安装包。更新保留独立数据目录，原程序目录另留 previous 时间戳备份。可通过开始菜单或 Windows 已安装应用列表卸载；卸载仍保留个人数据目录。需要备份时复制个人数据目录，并先退出系统。

当前安装包没有商业代码签名。若电脑安全策略不允许运行未签名程序，请由本单位管理员按现有规定处理，不关闭安全防护。安装版沿用浏览器界面；桌面图标负责自动启动和打开页面。

## 构建与验证

开发电脑先准备项目 `.venv` 与 requirements.txt，再运行 `python scripts/build_windows_installer.py`。构建仅收集公开应用白名单和运行时依赖，不扫描真实配置、课堂数据库、uploads 或用户原稿。构建产物与临时目录不加入 Git。

本机离线包、独立安装目录和本机服务启动可验证；未经过全新 Windows 电脑的实际安装演练时应如实说明，不能据此保证所有单位安全策略均允许安装。
