# 统一教学平台使用说明

平台名称：**生物实验智学助手**。模块一：**生物功能图谱**——探索基因、蛋白与代谢物的通路关联。模块二：**电泳异常分析**——结合实验记录与对照结果分析电泳异常，通过教师反馈和复测验证改进判断。

更新：2026-10-09。平台名称为“生物实验智学助手”，包含“生物功能图谱”和“电泳异常分析”两个模块。新网页支持电脑和手机浏览器；旧版 Streamlit 入口保留。

## 打开与关闭

当前电脑双击根目录“启动生物实验智学助手.bat”，等待启动窗口打开网页。也可双击“创建桌面快捷方式.bat”，以后使用桌面图标。结束时点击启动窗口“退出系统”；仅关闭网页不会关闭后台。

给其他电脑使用：运行 dist/生物实验智学助手安装程序.exe。安装版包含网页和 Python，使用者不需要安装 Node.js。首次在启动窗口设置教师访问码，可选填写 DeepSeek API Key；无 Key 仍可查询知识、填写记录并使用本地规则。

默认仅当前电脑访问。需要手机时，在启动窗口主动开启“手机／局域网访问”，按提示重启服务，再扫描二维码或输入地址。手机和电脑需在可互访网络，电脑保持运行；不自动修改防火墙。校园网设备隔离时可用可控热点测试。当前没有校外随时访问的线上服务。局域网模式仅用于可信教学网络，访问码不要转发给无关人员。

## 教师先准备课堂

1. 进入“教师工作区”，输入教师访问码。
2. 在“课程方案”填写已核实的条件，也可填入教师提供的 pET-28a(+) 讲义条件。浓度、目标片段、最佳退火温度等未知项保持空白，不根据体积推断浓度。
3. 在“课堂任务”填写题目和要求，选择课程方案，搜索相关知识词条并添加阅读提示，然后发布。
4. 将任务码告诉学生。发布时冻结题目、方案和知识引用；需要改动时“以此发布新版本”，原任务不覆盖。
5. 学生提交后，从“案例复核”选择案例，先依据原始记录独立判断。保存后再进入常规复核查看系统建议并给出反馈。共用访问码不区分教师个人身份；看过建议后不能补记为独立判断。
6. 可进行人工过程评价、复测复核、任务记录导出和班级问题分析。图像评估先保存独立参考，再明确确认发送处理副本，最后登记人工审计。

## 学生怎样使用

1. 在首页输入教师给的任务码，阅读要求及相关知识。没有任务码也可直接进入实验复盘。
2. 在“生物功能图谱”搜索中文、英文、别名，查看词条、三层关联及通路。图谱可拖动缩放，也可阅读文字关联列表。自动名称／标识符匹配不等于已确认生物关系；物种或来源未知时不补造。
3. 进入“实验复盘”，按四步填写课堂信息、实际观察、已知参数、自己的初判，只确认真实核对过的事实。图片可选，文字草稿保存在当前标签页；切换模块后返回可恢复文字，图片需要重新选择。不同设备不自动同步草稿。
4. 点击保存，等待后台成功提示，妥善保存私有查询码。不要把查询码给其他学生；换设备或服务重启后，在首页输入查询码找回。查询码不会放进网址。
5. 查看排查顺序并补充证据。分数不是概率，尚未核实的候选不能直接确认。图像 AI 需要主动预览、指定泳道身份并确认发送；其结果只作观察候选，逐项人工核对，与原因判断及成绩分别保存。
6. 收到教师反馈后，针对当前版本提交修订。先写验证计划，再实际完成复测并追加时间、改变与保持条件、对照、结果和解释。计划本身不能算作复测。
7. 完成任务中的新案例独立作答，并按需导出复盘报告。历史读取保存结果，不重新诊断或请求模型。

## 收藏、数据与更新

知识收藏保存在当前浏览器，可导出 JSON 再在另一浏览器导入。原生物功能图谱可先导出旧收藏，再在新平台导入；无法识别的条目会提示，不自动改指其他条目。课堂任务引用采用稳定词条编号与发布快照。知识查询不依赖模型联网。

项目模式默认沿用 data/app.db 与 uploads；首次统一平台升级旧库前创建 .before-unified-platform.bak 备份。安装版程序在 %LOCALAPPDATA%\Programs\BioLabReview，配置与教学数据在 %LOCALAPPDATA%\BioLabReview。更新前退出服务，独立数据目录保留，旧程序目录另留备份。备份时先退出，复制整个个人数据目录。不同电脑的数据不会自动同步。

本轮自动验证使用独立库和生成图片，没有读写课堂库。真实手机和另一台全新 Windows 电脑的验收需实际操作，不能用桌面模拟手机代替。

## 开发与回退

开发调试入口位于每个页面最底部，以灰色小字“开发调试”显示，也可直接访问 `/dev`。需输入独立的 `DEV_ACCESS_CODE`，教师访问码不能替代。尚未配置时，在启动器“配置”中设置调试访问码并重启服务；也可自行配置环境变量或 secrets，勿把访问码提交到仓库。

控制台提供系统自检、DeepSeek 配置状态、最近图像调用元数据、规则库查看校验和新增规则。自检不请求模型，不显示密钥、学生原始文字或图片。旧版的最近文本抽取信息属于原 Streamlit 页面会话，统一网页不会补造此记录。新增规则需先检查，再确认保存；默认停用，启用后影响后续诊断。保存前自动备份原规则到规则目录下的 `.rule-backups`；规则版本变化时须刷新后再检查。历史案例不重新诊断。程序升级前应另行备份自定义规则文件及 `.rule-backups`，安装包的标准规则不会自动合并自定义规则。

开发环境安装 Python 依赖，首次执行 npm ci --prefix frontend，再执行 npm run build --prefix frontend。启动命令为 python platform_server.py；所有 API 位于 /api/v1。品牌集中在 teaching_platform/config.py，可用 BIO_PLATFORM_NAME 和 BIO_PLATFORM_SUBTITLE 调整，不在网页里逐处修改。

旧版入口为“启动旧版实验复盘.bat”或 python -m streamlit run app.py；原生物功能图谱项目保持原样。正式接入课堂数据前先停服务并完整备份，若需回退数据应使用备份，不能用旧程序直接覆盖新版本记录。
