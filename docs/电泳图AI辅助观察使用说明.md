# 电泳图 AI 辅助观察使用说明

产品：生物实验智学助手；当前模块：电泳异常分析；实验专题：PCR 与电泳。

文档核对日期：2026-10-08。已实现首版；实际教学图片识别表现仍待教师标注验证。

## 管理员配置

在项目根目录 `.env` 中设置 `DEEPSEEK_API_KEY=自己的密钥`，或在 `.streamlit/secrets.toml` 中添加：

```toml
DEEPSEEK_API_KEY = "自己的 DeepSeek 官方 API Key"
DEEPSEEK_VISION_ENABLED = true
```

保留文件中原有教师与开发访问码。重启服务后生效。文字线索整理、追问和图像观察全部固定使用 `deepseek-flash`，无需设置模型名或接口地址。旧智谱密钥及 `BIGMODEL_*` 不再用于请求；请使用 DeepSeek 官方账号密钥。

关闭图片调用可把 `DEEPSEEK_VISION_ENABLED` 设为 `false`，不影响已存观察和人工核对。图像与文字调用按实际 Token 计费，同一账号可查看账单。

## 学生操作

1. 按原流程输入实验记录、上传 PNG/JPG 图像并完成独立初判。
2. 在结果页展开“电泳图 AI 辅助观察”。查看原图，按需要旋转、裁剪，确认即将发送的图像不含姓名、学号等身份信息。
3. 按发送区域从左到右填写泳道数量和身份。图像中的泳道数量与表格必须一致；身份未知就保留“身份未确认”。
4. 勾选发送确认，点击“AI 辅助观察”。刷新页面或修改表格不会自动请求。
5. 每项初始为“未核对”，未完成的项目可保持该状态。对照原图逐项选择“与原图一致”“已修正”或“无法确认”，填写人工备注并保存。看不清的数量保留空白，不能填 0。
6. 仅最新成功观察可继续核对；历史观察只读。同一设置的最新已保存观察可以直接复用。“重新识别”会再次调用并追加版本；图片或泳道设置改变后需重新识别，旧版本只读。

图像观察及人工核对均不自动改变原有输入、诊断排名、教师结论或分数。需要修订实验观察时，请通过原有输入或补证流程自行填写。

## 教师操作

在原案例详情展开“电泳图辅助观察与人工复核”，对照原图、发送区域、AI 原始候选和学生核对记录，逐项保存图像复核。图像复核与“最终原因”复核分别保存，不增加原因反馈版本、不自动要求学生重写原因修订。

学生再次核对后，原教师图像复核会标明对应旧版学生核对。历次观察与核对只读保留。TXT 复盘报告会加入已保存的图像候选和人工核对，导出时不调用模型。

## 功能范围

仅观察候选条带数量、现象、相对位置和亮度，提示图像模糊或过曝等问题。通用模型可能漏检弱带、误增条带或错配泳道；程序字段校验不证明图像内容正确。

不输出污染、模板不足等原因，不测量精确 bp 或 DNA 浓度，不自动评分。图像无法判读时保留未知；API 超时、失败、关闭或未配置时，仍可继续原有人工流程。

图片发送至 DeepSeek 官方服务，Base64 传输不代表本地识别或供应商零留存。原图本地保留，发送副本去除元数据；图像中的可见文字不会自动脱敏，发送前需人工检查裁剪。

## 验证

自动回归使用临时库和程序生成图片，不操作课堂库。可执行：

```powershell
.venv\Scripts\python.exe -m unittest discover -s tests -v
.venv\Scripts\python.exe scripts/verify_competition_ui.py
```

需要主动在线联调时执行 `scripts/verify_deepseek_live.py`，会发送固定匿名文字和程序生成图片，并消耗少量 Token。它不读取学生照片，也不证明真实电泳图的准确率；实际教学图片仍需教师提供脱敏标注后评估。

官方说明：[视觉 API](https://api-docs.deepseek.com/guides/vision/)、[模型及计费](https://api-docs.deepseek.com/quick_start/pricing/)。

## 独立图像评估入口

教师工作区新增“图像评估”：先独立保存参考，标记争议和未知，再主动请求模型；同原图族或同文件不能跨校准/独立验收集合。模型原始候选与人工泳道对应核验分别留痕，按质量、模型和提示词版本导出数量差及未知统计。数量差不定位具体漏检，重复调用不当独立图片。详细步骤见 [教学功能升级使用说明](教学功能升级使用说明.md)。真实电泳图参考与表现仍待收集。
