# 统一平台迁移对照与验收

更新：2026-10-09。实现分支：`codex/unified-teaching-platform`。保留原版 Streamlit 入口及原生物网络助手目录。正式课堂数据尚未切换，本轮仅使用隔离库与生成图片。

| 原有能力 | 统一平台入口与实现 | 验证与边界 |
| --- | --- | --- |
| 中文、英文、别名检索 | 知识网络；`knowledge.py` | 迁入 1586 个词条，查询无需模型 |
| 词条、三层图谱、通路 | 详情页、图谱及文字关联列表 | 节点跳转、缩放及手机尺寸实测；不推断方向或未知物种 |
| 原网页收藏 | 浏览器收藏、JSON 导入导出 | 原 `k` 字段可迁入；旧编号映射冻结，缺失明确提示 |
| 知识数据构建 | `build_knowledge_source.py`、`build_knowledge.py` | 实际从原工作簿重建，结果与迁入原数据一致；不依赖固定盘符 |
| 现象与独立初判 | 实验复盘四步表单 | 原始输入、事实确认和版本随案例保存 |
| 规则排序 | `experiment_business.py` 与原版共用 | 8 类现象、40 条主规则及 2 条组合；未核实自由描述不参与规则 |
| 定向追问与补证 | 案例内追问、候选整理及人工确认 | 初判与补证分别保留；空的新结果不能回退显示旧候选 |
| 私有查询码找回 | 首页找回、后台会话 | 详情、图片和报告均鉴权；查询码不进入网址 |
| 教师独立复核 | 教师工作区首先展示原始记录 | 查看建议后不能补记独立判断；改变判断须写依据 |
| 教师反馈及修订 | 案例复核与学生修订 | 对应反馈版本，过期提交拒绝，历史保留 |
| 验证计划与实际复测 | 案例内计划、复测及教师解释 | 计划不计作复测，原图不覆盖，失败上传可补传 |
| 人工过程评价 | 初判、当前反馈修订、新案例作答 | 未评价保持空白；不自动生成学生成绩 |
| 课程方案版本 | 教师课程方案 | 可填入已提供讲义条件，未知项不补造 |
| 课堂任务与知识联动 | 教师发布、学生任务页 | 方案和知识快照随发布冻结，新版本不覆盖旧任务 |
| 班级问题与教学建议 | 教师班级问题 | 默认真实课堂统计；模型只收聚合数量，动作受限 |
| 图像观察与师生核对 | 案例图像区 | 预览、同意、匿名映射后主动请求；三种记录独立留痕，不改变评分 |
| 图像参考评估 | 教师图像评估 | 先冻结独立参考，再请求模型；争议、未知与错配分开 |
| 历史与报告 | 案例详情、报告导出 | 读保存结果，不重新诊断或调用模型 |
| 双击与安装版 | 原启动入口、新安装包 | 默认本机；LAN 主动开启，程序、数据及配置分开 |

新网页的接口统一位于 `/api/v1`。权限由后台验证，网页不能自行声明已授权。原版界面通过 `core.py` 适配共享业务，没有复制第二套诊断规则。

回归基线包括原项目测试与迁移后新增验证，最终 90 项测试通过。Edge 浏览器完成任务到复测的完整师生流程，验证收藏迁移、图谱点击和图像预览；在 360、390、430、1366、1920 像素检查实际 DOM 边界并保存截图。受控图像候选另验证学生核对、刷新恢复和教师留痕，不能当作在线模型识图表现。

隔离 HTTP 负载测试为 20 人同时打开、查询、提交并各上传约 1.54 MB 的生成 JPEG，全部成功；仅记录当前电脑本机表现，不代表校园网络或其他设备性能。安装包校验、实际安装更新与重启结果见 `docs/competition/06_升级验收记录.md` 和 `build/qa/windows/verification.json`。

仍需实际完成：真实手机局域网操作、另一台全新 Windows 电脑安装，以及真实课程试用。未核定的模板浓度、目标片段、最佳退火条件、试剂品牌及对照设置继续标注待确认。正式切换前先停旧服务并备份课堂库及图片，不用课堂数据做测试；线上部署、账号系统和跨设备收藏同步不在本轮范围内。
