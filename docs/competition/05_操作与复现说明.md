## 正常教学启动

在项目目录安装 `requirements.txt`，用项目虚拟环境启动：

```powershell
npm ci --prefix frontend
npm run build --prefix frontend
.venv\Scripts\python.exe platform_server.py
```

打开 http://127.0.0.1:8501 。在环境变量或 Streamlit secrets 中配置自己的 `TEACHER_ACCESS_CODE` 和 `DEV_ACCESS_CODE`；学生端无需教师访问码。

系统界面面向日常教学，不显示比赛用途说明，也不提供示例载入与测试环境恢复入口。课堂页面仅展示课堂记录和待核实的历史记录，内部案例与规则校验记录保留在后台。

## 新案例与查询

学生按实际实验情况填写现象、参数及对照。第 3 步先写自己的判断，第 4 步确认事实后提交，生成建议后保存显示的查询码；操作描述自动整理只是建议，事实线索须手动选择。补证后保留前后结果。

教师登录后默认进入独立复核，先提交判断再查看候选；最终原因在“常规案例复核”保存，改变独立判断须填写理由。学生在“已有案例？用查询码找回反馈”输入查询码，提交有依据的修订。每个反馈版本允许一次提交；教师反馈内容改变后可再次修订。验证方案五项需齐全，按计划记录，教师可填写反馈。

## 电泳图 AI 辅助观察

在根目录 `.env` 或 `.streamlit/secrets.toml` 设置 `DEEPSEEK_API_KEY`，重启服务。文字和图片均固定使用 DeepSeek 官方 `deepseek-flash`，无需另设模型或地址；旧 `BIGMODEL_*` 不再生效。

学生上传图片并完成独立初判、生成规则建议后，在结果页展开“电泳图 AI 辅助观察”。人工设置方向、裁剪范围、泳道数量及身份，核对发送预览并勾选同意，点击“AI 辅助观察”。逐泳道标记未核对、与原图一致、已修正或无法确认，再保存。教师在案例详情中展开“电泳图辅助观察与人工复核”，对照原图和学生核对记录独立保存复核。报告包含候选与人工记录。

图像记录不直接改变原因排序或成绩。上传和刷新不自动调用；相同上下文可复用，主动重新观察会产生新用量。改变图片、裁剪或泳道身份后旧结果只作历史参考。图像不可判读保留未知，不能将未知数量写成零。可用 `DEEPSEEK_VISION_ENABLED=false` 暂停新请求。详细限制见上一级目录《电泳图AI辅助观察使用说明》。

## 恢复与保存

停止演示服务后运行：

```powershell
.venv\Scripts\python.exe demo_runner.py --reset-demo
```

只恢复 `data/demo/demo.db` 的固定模拟案例，遇到非模拟记录拒绝清理。课堂 `data/app.db` 与 `uploads/` 不参加演示恢复。首次启动升级版课堂环境，旧库会先备份为 `app.db.before-competition-upgrade.bak` 再扩展字段。新增图像记录表前对已有库生成 `app.db.before-gel-observation.bak`。原始文件与备份均保留，备份为迁移时的快照，不替代日常备份。

## 常见情况

- 图片文件：仅支持有效 PNG/JPG，≤10 MB；损坏图片会提示重新导出，不进入预览和保存。
- 无在线接口：使用本地整理与人工确认。可在课程与班级设置中启用本地模式。
- 未设置教师码：在环境变量或 Streamlit secrets 配置 `TEACHER_ACCESS_CODE`；调试入口配置 `DEV_ACCESS_CODE`。课堂中勿使用固定演示码。
- 查询码丢失：摘要无法反推查询码；教师仍可查看记录，学生需新建案例。不要在提交包中放真实查询码。
- 教师保存冲突：系统提示记录已更新，刷新后核对，不覆盖另一会话的新反馈。
- 端口占用：用 `python platform_server.py --port 8514` 指定空闲端口。
- 旧记录缺少快照：显示当时保存的结果和缺失版本提示，不偷偷重算。
- 课程条件：教师已提供质粒与梯度预设，可在“课程方案”核定并保存版本；未知浓度、片段及对照仍待确认，不凭体积和绝对温度给病因。
