# 操作与复现说明

产品名称：生物实验智析助手

副标题：面向本科生物实验教学的智能复盘工具

当前模块：PCR 与电泳实验复盘

## 演示启动

在项目目录，用 Python 3.12.14 安装 `requirements.txt`；本机直接运行：

```powershell
.venv\Scripts\python.exe demo_runner.py
```

打开 http://127.0.0.1:8513 。这是本机演示，未部署到公网。

| 入口 | 演示码 | 用途 |
| --- | --- | --- |
| 教师复核 | `demo-teacher` | 查看、确认、反馈与教学评价 |
| 开发调试 | `demo-dev` | 自检与演示恢复 |
| 学生查询 | `demo-case-1` | 阳性与样本无带，核查体系遗漏 |
| 学生查询 | `demo-case-2` | 阴性短带，区分污染与短片段产物 |
| 学生查询 | `demo-case-3` | 样本拖尾，核查上样过量，留待学生修订 |

固定码仅在固定演示路径生效，课堂环境仍使用自己的入口配置。三个案例、判断及备注均为模拟；配套 PNG 是明确标注的泳道示意图，不是实际电泳照片。默认真实课堂看板显示空数据；选择“模拟演示”才能查看演示指标。

## 新案例与查询

从学生端选择模拟案例并载入，检查参数及对照。第 4 步先写自己的判断，生成建议后保存显示的查询码；操作描述自动整理只是建议，事实线索须手动选择。补证后保留前后结果。

教师登录后展开案例，选择原因、注明证据等级及反馈。学生在“已有案例？用查询码找回反馈”输入查询码，提交有依据的修订。每个反馈版本允许一次提交；教师反馈内容改变后可再次修订。验证方案五项需齐全，按计划记录，教师可填写反馈。

## 恢复与保存

停止演示服务后运行：

```powershell
.venv\Scripts\python.exe demo_runner.py --reset-demo
```

只恢复 `data/demo/demo.db` 的固定模拟案例，遇到非模拟记录拒绝清理。课堂 `data/app.db` 与 `uploads/` 不参加演示恢复。首次启动升级版课堂环境，旧库会先备份为 `app.db.before-competition-upgrade.bak` 再扩展字段。原始文件与备份均保留。

## 常见情况

- 图片文件：仅支持有效 PNG/JPG，≤10 MB；损坏图片会提示重新导出，不进入预览和保存。
- 无在线接口：使用本地整理与人工确认。演示页面明确不调用模型。
- 未设置教师码：在环境变量或 Streamlit secrets 配置 `TEACHER_ACCESS_CODE`；调试入口配置 `DEV_ACCESS_CODE`。课堂中勿使用固定演示码。
- 查询码丢失：摘要无法反推查询码；教师仍可查看记录，学生需新建案例。不要在提交包中放真实查询码。
- 教师保存冲突：系统提示记录已更新，刷新后核对，不覆盖另一会话的新反馈。
- 端口占用：使用 `demo_runner.py --port 8514` 后访问新地址。
- 旧记录缺少快照：显示当时保存的结果和缺失版本提示，不偷偷重算。
- 课程条件待补充：按真实方案修改 `course_presets.json`；不凭体积和绝对温度给病因。

## 复现与材料边界

```powershell
.venv\Scripts\python.exe -m unittest discover -s tests -v
```

源码支持包排除 `.env`、secrets、真实数据库、照片、日志、虚拟环境、Git 元数据及旧 DOCX。接收者自行配置接口和课堂入口码，运行演示可复现模拟流程。测试通过只能证明覆盖范围内的软件行为，不能替代真实教学效果。
