## 统一平台验收（2026-10-09）

本次在 codex/unified-teaching-platform 分支实施已批准的合并方案，原 main 和生物网络助手目录保留。新平台采用 Vue 3 + TypeScript、FastAPI、SQLite 和独立只读知识 JSON；抽出纯业务模块并由新旧页面共用。品牌集中配置。

- 迁入 281 个代谢物、663 个蛋白／酶、618 个基因、24 个通路，共 1586 个词条。关联标明匹配依据与待核实状态，未知物种与来源不补造，图谱不宣称反应方向。原工作簿重建脚本已去除固定盘符并实际执行通过。旧收藏编号映射单独冻结，知识更新不按新数组位置改指旧收藏。
- 统一网页包含知识检索、详情、图谱、通路、收藏导入导出；学生初判、补证、教师独立复核、修订、验证计划、实际复测与报告；教师课程方案、课堂任务、人工评价、班级问题和图像评估。任务发布冻结课程方案及知识快照。
- 90 项测试通过，包含服务端鉴权、错误私有码、跨站写入拒绝、过期版本、无 Key、无效图片、旧库备份与历史只读、图像参考冻结及 20 人同时提交和上传。模型成功响应测试使用明确受控替身，不能当作真实识图效果。
- Edge 真实浏览器完成任务至复测全流程，检查图谱节点跳转、缩放、旧收藏导入及导出、图片预览和无 Key 时按钮禁用。360／390／430／1366／1920 像素检查首页、知识页、案例页和教师图像评估页面，记录 scrollWidth 与控件边界并保存新截图；页面无横向溢出、无脚本异常。证据在忽略的 build/qa/browser/，旧版截图不代替新页面验收。
- 本机 HTTP 集中访问补测：20 人各上传约 1.54 MB、1600×1200 的生成 JPEG，20/20 全部完成；提交最大 0.665 秒、上传最大 1.166 秒，整轮约 1.65 秒。证据 build/qa/load.json。仅为当前电脑本机回环结果，不代表真实校园网、普通电脑或模型吞吐性能。
- 双击默认本机模式；主动开启局域网后显示地址与二维码，不自动改防火墙。Windows 包含构建网页及 Python，不要求使用者安装 Node.js。安装包与安装更新验证结果另见下方最终交付记录。
- 测试使用独立库、生成图片、空 Key 和关闭真实配置读取，没有接入课堂数据库或学生图片。暂未正式切换课堂数据；真实手机局域网、另一台全新 Windows 电脑及真实课堂教学效果仍待实际验收。
